dreamDEX Perps – Feedback & Testing Reports

About

This repository contains testing feedback and reproducible issue reports for the dreamDEX Perps Builder Bounty on Somnia Tokyo Testnet.

The goal is to explore the dreamDEX Perps platform, test its API, SDK, documentation and user experience, and identify issues or improvement opportunities.

Scope of Testing

- REST API
- GraphQL API
- SDK functionality
- Documentation
- Application usability
- Testnet interactions

Feedback Reports

Individual reports will be documented in the "feedback/" directory.

Each report will include:

- Issue title
- Severity
- Affected area
- Steps to reproduce
- Expected behaviour
- Actual behaviour
- Supporting evidence

Important

Only genuine, reproducible findings will be submitted. No unverified issues will be presented as confirmed bugs.
